# FOC 裁剪回归

测试将裁剪前后的实际 C++ 源码分别编译运行，以相同输入逐行比较输出。仅用替身提供 Arduino 时间、I2C 返回字节及 MCPWM API，不在 Python 中重新实现 FOC 公式。

在项目根目录执行（需要 Python 3.9+、g++ 和 Git）：

```bash
python3 test/foc_regression/compare.py --reference-rev 9a3b8757acea816755bfd852b24da0cf9257b620
/home/bgzerol/.platformio/penv/bin/pio run
git diff --check
```

也可提供裁剪前的 `foc_motor` 目录：

```bash
python3 test/foc_regression/compare.py /path/to/reference/foc_motor
```

脚本在临时目录提取参考库、编译两套程序并比较输出，结束后自动删除临时文件。参考提交必须包含本轮裁剪前的接口；测试中的 `FOC_TRIMMED` 仅处理已删除的模式配置和恒零 Ud 参数。

## 覆盖内容

- 正负 Uq、零电压、过限电压、正负多圈电角度及六扇区边界。
- 3,000 个运行周期中的电阻/KV 补偿、轴反馈滤波、限压、使能切换及 `loopFOC()` → `move()` 输出顺序。
- `loopFOC()` 不触发传感器读取，停机时 `move()` 仍更新反馈。
- 自动方向/零点校准、预置方向、预置零点及无运动校准失败。
- PID 积分限幅、输出斜率限制、低通滤波及长时间间隔分支。
- AS5600 全量 12 位计数、双向跨圈、不同采样间隔和速度最小更新间隔。
- 实际 MCPWM 后端的四个槽位映射、默认/指定/限幅频率、计时器分频和周期、同步调用与占空比写入。
- 仅对裁剪版额外断言：MCPWM 初始比较值为零，资源耗尽返回失败。

通过时输出 33,479 行计算/状态记录一致，以及 92 行 MCPWM 记录一致。浮点数以十六进制输出，比较不使用误差容限。

## 覆盖边界

这是主机同输入回归，不是 ESP32 实机测试。GPIO、电气方向、MCPWM 寄存器生效时刻、I2C 失败、RTOS 调度、长时间戳回绕和实际循环耗时不在此测试范围。原版 MCPWM 未初始化的比较值不参与等价比较，裁剪版单独检查零初始化。

编译通过和主机结果一致不能替代上板后的启动校准、使能/停机、PWM 波形与电机表现验证。
